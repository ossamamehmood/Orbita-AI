## 🚀 Deployment Protocol

### 1. Initialize
```bash
git clone https://github.com/ossamamehmood/orbita-ai.git
cd orbita-ai
```

### 2. Configuration
Create a `.env` file in the root directory.
```env
GEMINI_API_KEY=your_neural_core_key
```

### 3. Execution
```bash
npm install
npm run dev
```
