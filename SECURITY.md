# Security Policy

## Supported Versions

Only the most recent version of Orbita AI is supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 3.4.x   | :white_check_mark: |
| < 3.4.x | :x:                |

## Reporting a Vulnerability

We take the security of our users seriously. If you discover a security vulnerability within Orbita AI, please follow the steps below to report it responsibly.

### 🛡️ How to Report

Please **do not** open a public issue for security-related bugs. Instead, send your report via one of the following methods:

1. **Email**: Send a detailed report to [security@ossamamehmood.com](mailto:hello@ossamamehmood.com).
2. **Private Disclosure**: Use the GitHub "Report a vulnerability" feature on the repository if available.

### 📝 What to Include

A high-quality report should include:
- A clear description of the vulnerability.
- Steps to reproduce (or a proof-of-concept script).
- Potential impact if exploited.
- Any suggested fixes or mitigations.

### ⏱️ Response Timeline

- **Acknowledgment**: Within 48 hours of receipt.
- **Initial Evaluation**: Within 5 business days.
- **Fix/Resolution**: We aim to resolve critical issues as quickly as possible, typically within 14 days.

### ⚓ Zero Days

We kindly ask that you follow **Responsible Disclosure** guidelines. Please allow us a reasonable amount of time to fix the issue before sharing any information publicly.

Thank you for helping keep Orbita AI secure!
